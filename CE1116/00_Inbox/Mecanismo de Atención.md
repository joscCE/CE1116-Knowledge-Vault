## 📚 Idea/Concepto 
Mapeo de un query y un conjunto de pares key-value a una salida, el output es una suma ponderada de los valores donde cada peso se determina mediante una función de compatibilidad. esta funcion de compatibilidad suele ser el producto punto escalado, la suma se normaliza mediante una función softmax para convertir las puntuaciones en una distribución de probabilidad.
